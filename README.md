## Overview

Instead of a traditional portfolio layout, this site is designed to feel like an iOS Messages conversation. Content is delivered as chat bubbles — projects appear as photo stacks you can tap through, and each section unfolds naturally as you scroll. Built with Angular and custom CSS to replicate the iOS aesthetic.

---

## Features

- iOS chat UI with conversation-style layout
- Dynamic photo stacks — clustered project screenshots that expand on interaction
- Memoji avatar with hover animation
- Thought-bubble navigation for section jumping
- Project cards with live links and custom previews
- Responsive design for desktop and mobile
