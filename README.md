# My Portfolio

A personal portfolio website featuring a unique, interactive **iOS-style chat interface**.

## ✨ Features

- **Interactive Chat UI**: Browse "messages" to learn about me and my projects.
- **Dynamic Photo Stacks**: iOS-inspired clustered photo layouts for a premium feel.
- **Project Showcase**: Clickable project links with custom previews.
- **Responsive Design**: formatting that looks great on desktop and mobile.

## 🛠️ Tech Stack

- **Framework**: Angular
- **Styling**: CSS (Custom iOS aesthetic)

## 🚀 Getting Started

To run this project locally:

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   ng serve
   ```

3. **Open in browser**:
   Navigate to `http://localhost:4200/`.
